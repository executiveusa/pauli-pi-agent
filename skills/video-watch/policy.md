# Video Watch Policy

## Authorization

Analyze only material that is public or that the user is authorized to access through an approved workflow.

Do not:

- Collect passwords, verification codes, cookies, session tokens, or authorization headers
- Bypass login, paywalls, DRM, geographic restrictions, or security challenges
- Use proxy rotation, fingerprint spoofing, or CAPTCHA-solving services
- Access locked lessons or private videos without explicit authorization

## Copyright and retention

Allowed:

- Private analysis for the user's own learning or authorized business review
- Short source excerpts when necessary for evidence
- Transformative summaries, notes, critiques, and knowledge units
- Timestamped references to source material

Blocked:

- Reproducing a complete transcript when it is not user-provided or licensed for that use
- Downloading or redistributing full protected videos
- Packaging source material as a substitute for the original course or video
- Publishing substantial copyrighted excerpts

Store source-derived material minimally. Prefer evidence spans, timestamps, summaries, and links over full duplication.

## Evidence hierarchy

Use evidence in this order when available:

1. Creator-provided transcript or captions
2. Platform-generated captions
3. Authorized local audio transcription
4. Approved external transcription
5. Selected visual-frame review
6. Metadata-only analysis

Never treat metadata or thumbnails as proof of spoken claims.

## Coverage disclosure

Every output must state one coverage label:

- `METADATA ONLY`
- `TRANSCRIPT REVIEWED`
- `AUDIO TRANSCRIBED`
- `VISUAL SEGMENTS REVIEWED`
- `FULL AUDIOVISUAL REVIEW`

When transcript and visual review both occur, explain which claims came from which evidence.

## Evidence labels

- `SOURCE STATES`
- `VISUALLY SHOWN`
- `STUDENT INFERENCE`
- `UNRESOLVED`
- `ACTION PROPOSAL`

A claim without traceable support must not be labeled as a source fact.

## Timestamps

Use timestamps only when they come from a transcript segment, media player position, chapter marker, or reviewed frame. Do not invent or estimate precise timestamps without marking them approximate.

## External processing

Before uploading audio, frames, or files to an external service:

1. Confirm the source is authorized.
2. Check whether local processing is available.
3. Minimize the uploaded segment.
4. Avoid personal, confidential, or client-sensitive material unless approved.
5. Record the processor in the run evidence.

## Digital Student memory policy

Video Watch may create candidate knowledge, links, and a proposed memory patch. It must not silently commit durable second-brain memory when the active workstream requires review.

Candidate knowledge must include:

- Source URL or source identifier
- Evidence location or timestamp
- Coverage label
- Evidence label
- Confidence
- Derived relationship, when applicable
- Review status

## Failure response

When the source cannot be processed, report:

- What was accessible
- What was unavailable
- Why processing stopped
- What alternative evidence would allow completion

Do not disguise a failed retrieval as a completed analysis.
