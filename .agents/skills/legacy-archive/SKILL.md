# Legacy Archive

## Purpose
Make the personal archive reconstructable years later even if a model, SaaS, database, or website disappears.

## Preserve
- source manifests and stable IDs
- export dates/versions
- checksums when available
- canonical schema version
- merge/dedupe ledger
- public-projection/publication receipts
- backup locations and restore procedure

## Rules
- Original sources are immutable evidence.
- Derived indexes/graphs are rebuildable.
- Prefer open, documented formats for durable exports.
- Never put secrets into archival manifests.
- Archive does not mean public: privacy labels and access boundaries survive export.
- Test restore from a bounded fixture/snapshot before claiming archival readiness.

## Output
Versioned archive manifest, integrity report, and restore instructions.
